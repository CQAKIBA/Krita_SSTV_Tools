# SSTV Toolbox for Krita — v0.1.5（試作版）

Kritaの右側やフローティングウィンドウに「SSTVツールボックス」を追加する**非公式**のPythonプラグインです。Krita本体・開発チームの公式配布物ではありません。MMSSTVなどで行うような写真・文字の組み立てを、Kritaの編集機能を使って簡単に行うことが目的です。

## ダウンロード

**[Kritaインポート用 ZIP (v0.1.5)](https://github.com/CQAKIBA/Krita_SSTV_Tools/raw/refs/heads/main/sstv_toolbox_krita_v0.1.5.zip)**（解凍しないでください）

## インストール / v0.1.4からの更新

1. 作業中の画像を `.kra` 形式で保存して、Kritaを終了／必要なら再起動する準備をしてください。
2. [sstv_toolbox_krita_v0.1.5.zip](https://github.com/CQAKIBA/Krita_SSTV_Tools/raw/refs/heads/main/sstv_toolbox_krita_v0.1.5.zip) をダウンロード（解凍不要）。
3. Kritaの **ツール → スクリプト → Pythonプラグインをインポート** からZIPを指定。
4. 既存プラグインの上書きを承認し、**Kritaを再起動**。
5. 必要なら **設定 → Kritaの設定を変更 → Pythonプラグインマネージャ** から有効化し再起動。**設定 → ドッキングパネル → SSTVツールボックス** から表示。

ZIPのトップレベルには `sstv_toolbox/` というディレクトリエントリを含めています（Kritaのインポータ対応）。プラグインID・設定保存先は前版と同じなので、プリセットやIPP URLは引き継ぐ設計です。

## v0.1.5の変更（2026-10-28）

- 操作パネルを一行表示に調整：`選択レイヤー\nを中央へ` → **選択レイヤを中央**。
- 背景判定ではKrita標準レイヤーの**名称を見ません**。最下層のRGBA/U8ペイントレイヤーを全ピクセル検査し、白色ピクセルまたは完全透明ピクセルのみ（混在も可）なら白紙として直上に背景を配置。複雑な構造、画像内容あり、形式不明では配置前に選択ダイアログを表示。
- 編集履歴の強制フローティング位置を、SSTVパネルやカーソル位置ではなく**Kritaメインウィンドウの幅・高さの30%位置**に変更。スクリーン内に収まるよう補正。
- 「Kritaのヘルプメニュー ▼」の隣に **GitHub** ボタンを追加。ブラウザーで [公式リポジトリ](https://github.com/CQAKIBA/Krita_SSTV_Tools) を開きます（非公式Kritaプラグインの公開場所です）。
- 著作権表示を `Copyright (c) 2026 Daisuke JA1UMW / CQAKIBA.TOKYO` に統一。

**注意**：`SSTV 背景` は当プラグインが管理する専用レイヤー名としてのみ使用しています。Krita標準の「背景」「Background」等の名前には依存しません。既存の `SSTV 背景` を再利用・差し替える操作は内容を破棄するので、重要な文書は事前に `.kra` 保存してください。

## v0.1.4の変更

### 1. 「操作」を6ボタンに整理

| 1行目 |  |  |
|---|---|---|
| 元に戻す | やり直す | 編集履歴 |
| 選択解除 | 選択レイヤーを中央へ | 全体表示 |

- **編集履歴** は左クリックで標準ドッカー表示/非表示（タブに隠れている場合は前面を試行）。**右クリック → フローティングで表示** で、なるべく画面内に配置。
- **選択レイヤーを中央へ** は「最後に貼ったもの」ではなく、今レイヤーパネルで選択しているものを対象に変更。ペイント/ベクターレイヤーのみ対応。ロックされた背景、グループ、内容のないレイヤーは移動しません。
- **全体表示** はKrita標準の「ビューに合わせる」アクション `zoom_to_fit` を呼び出すだけです。画像の位置そのものは変更しません。

### 2. フローティング時のサイズ変更ハンドル

- **ドッカーを浮かせた時だけ**、右下に28×28pxのQt標準 `QSizeGrip` を表示します。
- スクロールしても見えるように、内容スクロール領域の**外側**に配置。ドッキング時は非表示。
- Kritaの全体スタイルや他のドッカーの境界には変更を加えません。
- OS/Qtのウィンドウマネージャによって掴みやすさや表示が異なる可能性があります。

### 3. 「背景に貼り付け」のレイヤー順序を修正

- `SSTV 背景` という**このプラグイン自身の専用レイヤー**のみ置き換えます。通常のKritaレイヤーを名前だけで上書きしません。
- 最下層に白紙と判定できるペイントレイヤーがあれば、**その直上**へ専用背景を配置します（既存の文字・ワイプより下）。Krita標準背景の名前やUI言語には依存しません。
- 白紙判定はRGBA/U8の全ピクセルが白または透明かでチェックし、一定以上の巨大画像などは「不明」扱いにします。白い絵を描いた可能性まで識別するものではありません。
- 最下層に描画内容がある、またはレイヤー構造が複雑な文書は、**画像を配置する前に確認ダイアログ**を表示して、キャンセル/配置場所の選択ができます。複雑なグループでの強制的な最下層移動は行いません。
- 専用背景は更新後ロックされます。すでにv0.1.3で**最前面に置かれてしまった** `SSTV 背景` も、次の「背景に貼り付け」の際に位置の再判定を行います。

**注意:** 画像の書き換え、背景レイヤーの置き換え・並べ替えはUndoの1ステップにまとまらないことがあります。重要な作品では事前に `.kra` 保存を推奨します。

## 従来からの機能

- **新規キャンバス**: 640×480 / 640×512（RGBA・8bit、白いSSTV背景）。Krita起動直後はドッカーが出ない場合があるため、最初に通常の新規作成で文書を開いてください。
- **背景に貼り付け**: ファイルまたはクリップボードから読み込み。`□ フルサイズ` OFFなら縦横比維持で余白を白に、ONなら余白なしで中央トリミング。
- **ワイプとして貼り付け**: 10〜100%スライダー、既定値30%。100%は「画像全体がキャンバス内に収まる最大サイズ」。独立レイヤーへ貼り、移動ツールに切替。
- **テキストを貼り付け**: コールサイン、日付、時刻、日時、59、73、TNX QSOなど。プリセット登録・編集ダイアログ、Krita前景色連動、装飾なし/白黒フチ/白黒影。文字は確定済みラスターレイヤーです。
- **IPP送信**: 現在の画像をPNGに一時書き出し、IPP `Print-Job` で送信。PNG書き出しの設定ダイアログは通常省略されます。送信前にIPP URL・確認ダイアログが出ます。
- **ヘルプ**: Kritaの標準ヘルプメニューをボタン位置に表示し、Kritaについての入口も維持します。

## IPPと安全上の制限

- 送信先は設定画面から `ipp://127.0.0.1:631/printers/sstv` のような実際のサーバURLを指定。サーバ側で `image/png` に対応する必要があります。
- 認証、プリンタ探索、SSTV固有の送信モード属性には未対応。**IPP受付と無線送信完了は別**です。
- プラグインのラスタ画像書き込みはRGBA/U8（8bit）の文書に対応。複雑なベクター/マスク/グループを完全に操作する汎用ツールではありません。
- 背景再貼り付けは古い `SSTV 背景` レイヤーを置き換えるため、その専用レイヤーへの手描きは消えます。事前に `.kra` 保存をお願いします。
- KritaとQtのGUI操作は、この環境では**実機未検証**です。実際に動作確認できたのは以前のバージョンのユーザー環境のみです。初回は新規キャンバスで試してください。

## 開発者向け検証

```sh
python -m compileall -q sstv_toolbox
python -m unittest discover -s tests -v
```

この環境では純Pythonの配置判定、画像ジオメトリ、ドッカー識別、およびモックIPPサーバの通信を検証しています。Krita APIとQtの本物のUIについてはWindows上のKritaでのテストが必要です。
